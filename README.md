# Music Store SQL Analysis

## Project Overview

This project analyzes a relational music store database using PostgreSQL. The analysis focuses on customers, invoices, artists, tracks, genres, and sales data to answer business-oriented questions.

## Tools & Technologies

- PostgreSQL
- SQL

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- DISTINCT
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- ROW_NUMBER()
- LIMIT

## Analysis Performed

- Identified the senior-most employee based on job title.
- Analyzed invoice distribution across countries.
- Identified the highest-value invoices.
- Determined the city generating the highest revenue.
- Identified the highest-spending customer.
- Analyzed customers who listen to Rock music.
- Identified the top 10 Rock artists based on number of tracks.
- Compared track lengths with the average song length.
- Analyzed customer spending on the best-selling artist.
- Identified the most popular music genre in each country.
- Identified the highest-spending customer in each country.

## Project File

`music_store_analysis.sql` contains the SQL queries used for the analysis.
